# Comparative-Analysis-of-Motif-Finding-Algorithms-in-DNA-Sequences-with-Implanted-k-d--mers.
During my learning journey, I completed a comprehensive research project focused on the challenge of motif discovery in DNA sequences. The project simulated the motif finding problem by implanting mutated (k,d)-mers into synthetic DNA sequences and implemented five motif detection algorithms: Greedy Motif Search, Randomized Motif Search, Gibbs Sampling, Genetic Algorithm, and Cluster Refinement Algorithm. I evaluated these algorithms using performance metrics such as Hamming distance, accuracy, and recall across multiple test cases with varying mutation levels. The analysis concluded that the Gibbs Sampling algorithm offered the most robust performance overall. The project was conducted using Python and involved in-depth algorithmic implementation, result visualization, and comparative performance analysis.
